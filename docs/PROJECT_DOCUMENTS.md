# 完工・見積・請求（v5.7.0）

管理者でログインし、ホームの「現場・見積・請求」から現場を選びます。登録管理にも入口があります。

- **完工設定**：完工日を保存すると、通常の日報の現場候補から外れます。過去の日報・費用・書類は残ります。「工事中に戻す」で再開できます。完工は費用の確定や入金済みを意味しません。
- **見積書**：品名・規格・数量・単位・見積単価を入力して積算します。原価単価は任意の社内情報で、入力が揃うと見込利益を表示します。原価と見込利益は印刷しません。登録済みの人・車両・重機・工具等の単価を原価として取り込めます。
- **請求書**：請負金額がある場合は未請求残額を明細に入れて開始します。確定した見積から明細を引き継ぐこともできます。
- **出来高請求書**：累計出来高を金額または率で入力し、前回までの確定済み請求額を引いた今回分を計算します。請負金額を超える請求は保存・確定時に確認します。

最初に「発行者・振込先の設定」で自社情報を登録してください。登録番号は、登録している場合に入力します。宛先・件名・取引日・支払期限を確認し、**下書き保存 → プレビュー → 内容を確定・採番 → 印刷・PDF保存**と進みます。

書類番号は確定時に自動で付きます。確定済み書類の内容は固定され、取消理由を残して取り消せます。後続の請求書がある場合は新しいものから取り消します。取消済み書類も履歴に残ります。相手先への自動送信はありません。

請求書は既存の請負売上へ二重加算しません。確定済み見積は、金額を確認して「この見積額を請負金額に設定」を押したときに限り、請負金額・利益計算へ反映します。未請求額は入金残高とは別の指標です。

数量は小数3桁、単価は小数2桁まで。明細金額の1円未満は切捨て、消費税は書類全体の税別小計から1回だけ切り捨てます。1書類内の税率は統一し、10%・8%（軽減税率）・非課税／対象外を選べます。税率別の記載事項と端数処理は、[国税庁の記載事項](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6625.htm)・[端数処理](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6371.htm)を参照しています。

## 検証

`node tests/project-documents.cjs` で積算・出来高・印刷内容を検証します。`tests/project-business-ui.cjs` は jsdom を用いた実際のフォーム操作の検証です。`tests/project-documents-database.sql` はトランザクション内で番号・同時更新・取消・権限・完工を検証するためのSQLで、検証後は必ずロールバックします。既存の日報や請負金額の書き換えは行いません。
