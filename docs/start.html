はじめての登録・社員の参加

会社の管理者は会社を登録します。社員IDを受け取った方はメール不要の社員ログインを使ってください。メールの参加リンクを受け取った場合のみ、この画面で参加します。

① メールアドレスを確認する

新規登録は12文字以上。他の人とパスワードを共有しないでください。

確認メールが届いたらリンクを開いてください。迷惑メールも確認し、確認後はこの画面に戻ってログインできます。

② 利用する会社を設定する

会社登録後、販売元が契約を確認して利用を開始します。社員名・車両・重機などは利用開始後に追加できます。他社の情報は入りません。

参加リンクから自動入力されます。管理者が指定したメールアドレスでログインしてください。別の端末でメールを確認した場合は、参加リンクをもう一度開いてください。
